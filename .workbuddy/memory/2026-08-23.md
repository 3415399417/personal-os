## 已修复（21:40 起，用户说「先不做移动端」）
用户确认跳过移动端，修其余问题（暗色 today 顶部白卡 / 资源中心对比度 / 今日空分组进度条），并扩大为「暗色模式对比度」根因修复。
- 改动文件：`app/pages.css`（末尾追加 `[data-theme="dark"]` 修正块，约 2705–2765 行）、`app/today/page.tsx`（空分组进度条条件渲染）。
- 根因：① 大量卡片主文字写死 `#111`，暗底 `--surface` 上几乎不可见；② 标签/链接用 `var(--accent-deep)`（暗紫），暗底对比不足；③ `--white` 暗色被改近黑，主按钮文字发暗。
- 修正：#111 主文字 → `var(--fg)`；标签/链接/小标题/按钮文字 → `var(--accent)`（注意 prototype.css 暗色 `--accent-soft` 实为 `#8B5CF6`，对比度临界，故用更亮的 `--accent` #A78BFA ≈6:1）；`start-card` 白渐变 → 暗色渐变；`res-row-cell` 白底/#111 → 暗面/亮字；`.btn-primary` 文字改 `#fff`。
- today 空分组（`total===0`）进度条不再渲染，避免空轨道被误读为满格。
- 验证：用 `_verify/verify-dark.mjs` + `verify-dark2.mjs` 读 getComputedStyle（图片工具被过滤，无法肉眼看截图，改用计算样式程序化验证）；`tsc --noEmit` 通过；暗色截图已刷新在 `_verify/review-shots/`。
